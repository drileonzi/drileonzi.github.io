    In the second week we had hands on introduction and practice on Python programming and Chemcomp simulation software at guest o#ce star plan. This is a powerful 1D and 2D simulation software in Astrophysics which is important to simulate protoplanetary disk and plant formation using the appropriate parameters. Here were able to write some basic scripts and generate simulation plots.
